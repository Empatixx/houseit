title: Stairs, shafts, ramps and columns
description: Structure that spans storeys.

## add-stair

Measured stair flights from one storey up to another. The riser height follows the two floors.

```bash
add-stair --level ground --to "1. patro" --thickness 200 --colour '#bdbdbd' \
  --flights '[{"x":2000,"y":1000,"direction":"north","width":1100,"going":280,"risers":9,
    "landing":[{"x":1450,"y":3520},{"x":3650,"y":3520},{"x":3650,"y":4620},{"x":1450,"y":4620}]},
    {"x":3100,"y":3520,"direction":"south","width":1100,"going":280,"risers":9}]'
```

`--flights` gives each flight's lower-end centre, uphill direction, clear width, going, risers, and the landing after it. `--base-offset` adjusts the first floor locally. `remove-stair --id` removes the flights and restores the floor opening.

## add-shaft

A lift shaft, or a services shaft with `--kind services`, from one storey up through another.

```bash
add-shaft --x 5000 --y 4000 --width 1600 --depth 1800 --to "3. patro"
```

`--enclosure` gives the shaft walls' thickness and colour, and optionally a door. `--around-columns` lets an enclosed services shaft wrap structural columns. `remove-shaft --id` removes it and restores the slabs.

## add-ramp

```bash
add-ramp --x 1000 --y -2000 --width 1500 --length 6000 --direction north \
  --thickness 200 --colour '#9e9e9e' --to-elevation 300
```

A ramp up to `--to` (a storey) or `--to-elevation` (millimetres above the building datum). `x,y` is the centre of its lower end. `remove-ramp --id` removes it.

## add-column

```bash
add-column --x 6000 --y 6000 --width 300 --depth 300 --colour '#cfcfcf'
update-column --column c1 --width 400
remove-column --column c1
```

A structural column from its storey's floor to the soffit. `--embedded` sets it into a wall, `--outside` allows an exterior support.
